# ODY 최종 발표 Q&A

`index.html` 을 브라우저로 열면 됩니다. **인터넷 연결 없이 동작합니다.**

## 조작
- 홈에서 카테고리 클릭 → 오른쪽에 질문 목록 → 질문 클릭 → 해당 장표로 이동
- `→` `←` 또는 화면 클릭 : 장표 이동
- 좌상단 모서리에 마우스를 올리면 **뒤로가기** 버튼이 나타남 (`Esc` 도 동일)
- `F` : 전체화면 / 홈에서 `1`~`5` : 카테고리 선택
- 홈 검색: `/` 로 포커스 → 키워드 입력 → `↑` `↓` `Enter` 로 이동, `Esc` 지우기
  (제목에 들어간 것 먼저, 그 다음 장표 내용에 들어간 것)

## 검색 색인
장표 내용을 고친 뒤에는 `node build-search.js` 를 한 번 실행하세요. (`assets/search-index.js` 재생성)

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 홈 (카테고리 + 질문 목록) |
| `01-planning.html` | 기획 Q1~Q5 · 5장 |
| `02-feature.html` | 기능 Q1~Q28 · 37장 (주변 탐색 / 여정 / 따라가기) |
| `03-domain.html` | 도메인 Q1~Q18 · 18장 (데이터 정제 / 소리 좌표 / 파이프라인 / 검증 / 운영) |
| `04-ai.html` | AI Q1~Q4 · 4장 |
| `05-reserve.html` | 예비 Q1~Q3 · 3장 (인프라 / 무중단 배포 / 인증) |
| `assets/` | 공용 CSS · JS · 폰트 |

질문 목록을 고치려면 `index.html` 아래쪽 `DATA` 객체만 수정하면 됩니다.
(`s` 값 = 이동할 장표 번호)
